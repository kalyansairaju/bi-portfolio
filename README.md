# Kalyan Sai Raju — BI Portfolio

Separate Power BI / BI version of my portfolio. Static HTML, CSS and JavaScript; no paid services or build step.

## Update your site
1. Replace `photo.jpg` with your new photo using the same filename.
2. Replace `resume.pdf` with your latest BI résumé.
3. Edit `index.html` for experience, contact details and links.
4. Edit `bi.css` for BI colors and layout; shared base styles are in `styles.css`.
5. Edit `dashboards.js` for synthetic demonstration data and measures. Keep demo data clearly labelled and do not upload private client data.
6. Commit changes to the repository's main branch. GitHub Pages publishes automatically.

The interactive dashboards are browser demonstrations, not PBIX reports. All displayed numbers are synthetic. Professional work descriptions are based on the supplied résumé.
